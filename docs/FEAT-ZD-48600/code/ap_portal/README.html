renderOverdueRisk takes the parsed CT-1 JSON from ap_aging ({id, vendor, days, amount, risk} rows). It escapes id and vendor, keeps amount as a string (never a float) and throws TypeError on a contract violation. See docs/ap_portal.md for inputs, outputs, errors and examples.
